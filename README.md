# 📚 CGPA Calculator

A fast CGPA Calculator Mobile App for University Students. Built in Rust and Slint with an inbuilt PDF generator for per level CGPA graphs 

## ✨ Features

- **Semester management** – Add multiple semesters, each with its own level (100L – 800L) and select (First / Second).
- **Course entry** – Add courses with code, title, credit units, and grade (A–F). GPA is calculated automatically per semester.
- **Bulk import** – Paste a formatted list of courses from the clipboard. Perfect for transferring from spreadsheets or grade reports.
- **CGPA calculation** – Overall CGPA across all semesters, with class standing (First Class, Second Class Upper, etc.).
- **Level breakdown** – See GPA per level, first/second semester comparison, and level CGPA.
- **PDF export** – Generate a complete PDF report of your academic record, saved to your Downloads folder (available in About).
- **Themes** – Light, dark, and a hidden “pink” theme (tap the Home/Clipboard/Semesters/Breakdown/CGPA/About icon 4 times).
- **Ad‑supported** – Non‑intrusive ads appear only after bulk import or PDF export, to support development.
